# semana1-git

Repositorio de práctica para la actividad de la primera semana del curso de control de versiones.

## Objetivo

Practicar el flujo básico de git y GitHub: inicializar un repositorio, hacer varios cambios en archivos, registrar el historial con commits y subirlo a un repositorio remoto.

## Contenido

- `datos.md`: información básica de la práctica.
- `script.py`: script de Python de ejemplo.

## Cómo usar

```bash
python3 script.py
```
